# 연구 근거

이 폴더는 현재 구현 결정을 이해하는 데 계속 필요한 근거만 보존해요. backlog, 작업 계획, 리뷰 기록과 완료된 조사 결과는 Git 기록에 맡겨요.

- `external/`은 검토일과 1차 출처, 채택 여부, 출처 제약과 로컬 근거를 기록해요.
- `internal/`은 소스만으로 이해하기 어려운 저장소 내부 결정을 기록해요.
- `TEMPLATE.md`가 형식을 제공해요.

공공데이터 포털의 API 명세, 행정표준코드, 라이선스 조건처럼 시간에 따라 바뀌는 사실은 사용할 때마다 1차 출처에서 다시 확인해요. 외부 자료는 동작을 판단하는 근거일 뿐 코드, 브랜드, API, asset과 token을 복사할 권한이 아니에요.

현재 구현의 최종 근거는 `specs/`, 소스와 테스트예요. 근거가 오래되었거나 로컬 근거가 사라졌거나 구현과 같은 내용을 반복하면 노트를 갱신하지 않고 제거해요.
