# 도메인

파이프가 주고받는 타입과 순수 로직을 둬요. 화면, 저장소, 네트워크를 모르는 코드만 여기에 있어요.

## 경계

- React, DOM API, `localStorage`, `fetch`를 가져오지 않아요. `crypto.getRandomValues`처럼 런타임이 모두 제공하는 것만 써요.
- 앱과 다른 패키지를 가져오지 않아요. 의존은 한 방향이에요.
- 제품 문구와 라우트 경로를 두지 않아요.

## 규칙

- 타입은 스펙이 정한 계약을 그대로 옮겨요. 스펙에 없는 필드를 추가하지 않아요. 근거 스펙 경로를 JSDoc에 남겨요.
- 밖에서 들어온 값은 `parse*` 함수로 검증하고 실패하면 `null`을 돌려줘요. 도메인 타입으로 단언하지 않아요.
- 검증 실패를 조용히 넘기지 않아요. 호출자가 몇 개를 버렸는지 알 수 있어야 해요.
- 상태는 저장하지 않고 유도할 수 있으면 유도해요. 따로 저장하면 내용과 어긋나요.
- 함수는 순수하게 두고 시각과 난수는 인자로 받을 수 있게 열어둬요. 그래야 테스트가 시간을 고정할 수 있어요.

## 테스트

- 검증기는 통과 경로 하나와 거부 경로 전부를 테스트해요. 거부 경로는 `it.each`로 표를 만들어요.
- 식별자 형식, 상태 유도, 경계 검증은 반드시 테스트해요.
