# 연구 노트 템플릿

외부 근거는 `research/external`, 저장소 내부 결정은 `research/internal` 아래의 설명적인 kebab-case 파일에 작성해요.

## 외부 근거

```markdown
# 주제

- Reviewed: YYYY-MM-DD

### Sources

- [공식 또는 1차 출처](https://example.com/source)

### Adopt

- 저장소에 채택한 원칙을 해요체로 설명해요.

### Do Not Adopt

- 복사하거나 채택하지 않은 범위를 해요체로 설명해요.

### Provenance

- license, 검토 revision과 복사 제약을 해요체로 설명해요.

### Local Evidence

- `packages/example/source.ts`
```

## 내부 결정

```markdown
# 저장소 결정

### Decision

- 현재 결정을 해요체로 설명해요.

### Rationale

- 별도 문서가 필요한 이유를 해요체로 설명해요.

### Local Evidence

- `apps/example/source.ts`
```
