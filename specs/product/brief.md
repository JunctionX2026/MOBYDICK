## 한 줄 정의

흩어진 공공데이터를 찾아서, 붙여서, 쓸 수 있는 형태로 내보내요. Discover → Compose → Serve.

## 문제

1. **어떤 데이터를 써야 할지 모른다.** 질문은 있는데 그 질문에 맞는 데이터가 어디에 있는지, 어떤 컬럼을 봐야 하는지 알 수 없어요. 포털 검색은 키워드 매칭이라 "쓰레기"로 찾으면 "생활폐기물"을 못 찾아요.
2. **쓰기까지 과정이 길고 반복된다.** 데이터 찾기 → 활용신청 → 키 발급 → 테스트를 데이터마다 처음부터 반복해요.
3. **붙이는 게 어렵다.** 같은 지역이 "경상북도 포항시 북구", "포항북구", `47113`으로 제각각이에요. 시간 단위와 측정 단위도 데이터마다 달라요.
4. **AI가 쓸 수 없다.** MCP로 제공되지 않아 AI가 직접 다루지 못해요.

## 파이프

| 단계 | 기능              | 하는 일          | 다음으로 넘기는 것   |
| ---- | ----------------- | ---------------- | -------------------- |
| ①    | 그래프 지식 베이스 | 찾는다           | 제안 (데이터 + 컬럼) |
| ②    | 워크플로 캔버스    | 붙인다 · 확인한다 | 완성된 워크플로      |
| ③    | 배포 (API / MCP)   | 내보낸다         | -                    |

파이프는 프로젝트 안에서 돌아요. 프로젝트는 질문 하나와 그 질문이 만든 워크플로를 담아서, 중간에 그만둔 작업을 다시 열 수 있게 해요. 정의는 [`../features/004-project.md`](../features/004-project.md)에 있어요.

세 기능은 병렬 기능이 아니라 직렬 파이프예요. 각 단계가 앞 단계의 출력을 먹어요. 그래서 먼저 정할 것은 기능이 아니라 접합부예요.

| 접합부   | 내용                                      | 없으면                      | 스펙                                                             |
| -------- | ----------------------------------------- | --------------------------- | ---------------------------------------------------------------- |
| A (①→②) | 그래프의 제안이 캔버스 노드·링크로 꽂히는 형식 | 발견과 조립이 따로 놀아요   | [`../features/010-seam-suggestion-to-canvas.md`](../features/010-seam-suggestion-to-canvas.md) |
| B (②→③) | 완성된 워크플로가 배포 단위가 되는 형식   | 배포가 별도 구현이 돼요     | [`../features/011-seam-workflow-to-deployment.md`](../features/011-seam-workflow-to-deployment.md) |

접합부는 한 사람이 책임져요. 기능별로 나누면 접합부는 아무도 안 맡아요.

## 범위

### 하는 것

- 경북 시군 단위로 조인 가능한 데이터 중심으로 다뤄요.
- 데모에서 끝까지 완결되는 경로 하나를 만들어요.
- 지역코드를 정규화해요.
- 제외된 행과 사유를 표시해요.
- 질문 단위로 프로젝트를 만들어 두고 다시 열어요.

### 안 하는 것

- 모든 공공 API 자동 연동
- 범용 n8n 대체
- 임의 코드 실행
- 실시간 스트림 처리
- 인과 추론
- 회원가입 · 권한 관리

## 제품 원칙

- **중간 결과물을 보여줘요.** 공공데이터 파이프라인의 실패는 조용히 일어나요. 어느 스텝에서 이상해졌는지 사용자가 판단할 수 있어야 하고, 그 판단을 쉽게 만들어야 해요.
- **만족은 사용자가 결정해요.** 시스템은 감지할 수 있는 것만 막고, 판단이 필요한 것은 막지 않고 보여줘요.
- **AI는 스펙을 만들고 실행은 코드가 해요.** 모델이 만든 코드를 실행하지 않아요.
- **일회성 분석은 자산이 아니에요.** 공공데이터는 연 단위로 갱신되므로 "같은 조합을 매년 다시"가 실제 수요예요.
