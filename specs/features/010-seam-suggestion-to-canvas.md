# 접합부 A: 제안 → 캔버스

- 상태: agreed
- 갱신: 2026-08-23
- 소유: (미정)

## 문제

그래프가 "A 데이터의 `a`·`b` 컬럼과 B 데이터의 `c` 컬럼이 어울려요"라고 답해도, 그 답이 캔버스에 그대로 꽂히지 않으면 사용자가 노드를 손으로 다시 만들어야 해요. 발견과 조립이 따로 놀면 파이프가 끊겨요.

## 사용자와 사용 시점

질문을 입력해 제안을 받은 사용자가 "이걸로 시작할게"를 누르는 순간이에요.

## 범위

### 하는 것

- 제안 하나를 캔버스의 노드와 링크로 변환하는 형식을 정의해요.
- 제안이 근거로 제시한 조인 키를 링크의 초기 의도로 옮겨요.
- 추천 파이프라인은 데이터 소스와 질문 기반 `조인·변환` 노드, 출력 노드로 변환해요.
- 추천 파이프라인을 배치한 뒤 사용자가 `조인·변환` 노드를 중간 실행해 결과와 조인 제외 사유를 확인할 수 있어요.
- 사용자가 제안을 수정한 뒤에도 같은 형식으로 캔버스에 넣어요.

### 안 하는 것

- 제안을 자동 실행하지 않아요. 캔버스에 배치까지만 해요.
- 여러 제안을 한 번에 합치지 않아요.

## 동작

1. 사용자가 제안 목록에서 하나를 고르고 캔버스로 보내요.
2. 제안에 포함된 데이터셋 수만큼 데이터 소스 노드가 생기고, 질문의 조인·변환을 나타내는 연산 노드와 출력 노드가 생겨요.
3. 제안이 제시한 조인 키가 링크의 자연어 의도 초안으로 채워져요.
4. 사용자가 중간 노드를 지우거나 추가하고 링크 문장을 고칠 수 있어요.
5. 이후 실행은 [`002-workflow-canvas.md`](002-workflow-canvas.md)를 따라요.

## 계약

`Suggestion`은 다음을 반드시 포함해요. 형식이 확정되면 `packages`의 스키마와 이 절을 함께 갱신해요.

| 필드              | 뜻                                                   |
| ----------------- | ---------------------------------------------------- |
| `datasets[]`      | 제안이 쓰는 데이터셋과 실제로 필요한 컬럼 목록        |
| `joinKey`         | 조인 기준이 되는 `key` 개념과, 데이터셋별로 대응하는 컬럼 |
| `intent`          | 왜 이 조합인지에 대한 한 문장                        |
| `evidence[]`      | 질문에서 데이터셋까지 지나온 그래프 경로             |

`joinKey`는 개념 하나와 데이터셋별 컬럼 대응을 함께 가져요. 컬럼 이름만 넘기면 캔버스가 정규화 방법을 다시 추론해야 해요. 개념과 컬럼 대응은 [`../product/glossary.md`](../product/glossary.md)의 그래프 모델을 따라요.

`Suggestion` → `{ nodes: CanvasNode[], links: CanvasLink[] }` 변환은 순수 함수 하나로 두고, 그래프와 캔버스 양쪽이 이 함수만 거쳐요. 변환된 연산 노드는 질문과 `joinKey`를 함께 검토할 수 있어야 해요.

## 인수 기준

- [ ] 제안 하나를 선택하면 손으로 노드를 만들지 않고 소스, 조인·변환, 출력 캔버스가 채워져요.
- [ ] 링크의 자연어 의도에 제안의 조인 키가 문장으로 들어가 있어요.
- [ ] 추천 파이프라인에서 전체 실행 전에 조인·변환 노드의 중간 실행 버튼을 누르는 안내가 보여요.
- [ ] 변환 함수에 스펙에 없는 필드를 넣으면 타입 검사에서 막혀요.
- [ ] 제안의 근거를 캔버스에서도 다시 확인할 수 있어요.

## 실패와 정지 조건

| 감지                             | 사용자에게 보이는 것                 | 진행 여부       |
| -------------------------------- | ------------------------------------ | --------------- |
| 제안한 컬럼이 실제 응답에 없음   | 어떤 컬럼이 사라졌는지 표시          | 노드는 만들되 링크는 비활성 |
| 조인 키가 두 데이터셋에 모두 없음 | 조인 키 없음을 표시                  | 링크 생성 안 함 |

| 근거(`evidence`)를 캔버스에서 보여주는 위치   | 캔버스 UI 결정 시 |           |
