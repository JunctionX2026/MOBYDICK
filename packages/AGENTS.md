# 패키지 작업 안내

`packages/*`는 앱이 공유하는 도메인 로직, UI, 설정이에요. 여기 있는 코드는 앱과 배포 런타임 어느 쪽에서도 같은 결과를 내야 해요.

## 규칙

- 워크스페이스 이름은 `@mobydick/<디렉터리 이름>`을 사용하고 앱은 `workspace:*`로 참조해요.
- 도메인 패키지는 프레임워크와 브라우저 API에 의존하지 않아요. 순수 함수와 타입만 둬요.
- 접합부 타입(`Suggestion`, `Workflow`, `OperationSpec`)은 패키지 하나가 소유하고 앱은 그 타입만 import해요. 앱에서 같은 모양을 다시 정의하지 않아요.
- 스키마 검증과 도메인 타입은 같은 곳에 두고, 검증을 거치지 않은 값이 타입 경계를 넘지 않게 해요.
- 실행기(연산 스펙을 실제로 계산하는 코드)는 패키지에 두고 캔버스와 배포가 같은 함수를 호출해요.
- 새 패키지를 만들면 그 폴더에 `AGENTS.md`를 만들고 루트 [`AGENTS.md`](../AGENTS.md)의 저장소 지도에 한 줄을 추가해요.
- 각 패키지는 `lint`, `typecheck`, `test` 스크립트를 제공해요.
- 단위 테스트는 소스 옆 `*.test.ts`, 타입 계약은 `*.type-test.ts`에 둬요.
