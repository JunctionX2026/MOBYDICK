# ② 워크플로 캔버스

- 상태: draft
- 갱신: 2026-08-22
- 소유: (미정)

## 문제

공공데이터 파이프라인의 실패는 조용히 일어나요. 연결이 실패하거나, 데이터가 깨지거나, 만들어지긴 했지만 사용자가 원한 결과가 아니에요. 어느 스텝에서 이상해졌는지 판단할 수 있어야 하고, 그 판단을 쉽게 만들어야 해요.

`A → B → C`에서 `A→B` 결과를 사용자가 직접 보고 판단해요. 데이터에 대한 만족은 결국 사용자가 결정해요.

## 사용자와 사용 시점

제안을 받았거나 직접 데이터를 고른 사용자가 조인과 가공을 만들고 확인하는 단계예요.

## 범위

### 하는 것

- 데이터를 노드로 배치하고 노드 사이를 링크로 연결해요.
- 링크에 자연어로 의도를 쓰면 AI가 선언적 연산 스펙으로 바꿔요.
- 사용자가 조인 키, 연도, 방식을 검토하고 승인해요.
- 각 노드의 중간 결과를 항상 볼 수 있고, 카드 우클릭이나 상단 실행으로 해당 단계까지 실행해요.
- 지역코드를 정규화하고 제외된 행과 사유를 표시해요.

### 안 하는 것

- 임의 코드를 실행하지 않아요. AI는 스펙만 만들고 실행은 결정적인 코드가 해요.
- 범용 n8n을 대체하지 않아요.
- 실시간 스트림을 처리하지 않아요.

## 동작

1. 제안받은(또는 직접 고른) 데이터를 노드로 배치해요.
2. 두 노드를 연결하고 링크에 자연어로 의도를 써요.
   > "2024년 시군구 기준으로 맞추고 인구 1,000명당으로 바꿔서 조인해줘"
3. AI가 이를 선언적 연산 스펙으로 바꿔요.
4. 사용자가 조인 키, 연도, 방식을 검토하고 실행 여부를 결정해요.
5. 카드 우클릭의 `실행` 또는 상단 `실행`을 선택하면 해당 노드까지의 선행 소스를 실행해요.

## 결과 표시

노드 카드는 항상 작게 요약을 보여줘요.

```
행 152 → 19   컬럼 7   결측 4%   ⚠ 매칭 68%
```

노드를 클릭하면 패널에 상세가 열려요. 기본은 표이고, 데이터 모양에 따라 차트 1종을 추가해요.

| 데이터 모양      | 차트            |
| ---------------- | --------------- |
| 지역 + 숫자 1개  | 지도 또는 막대  |
| 숫자 2개         | 산점도          |
| 시간 + 숫자      | 선              |
| 그 외            | 표만            |

## 계약

- 입력은 [`010-seam-suggestion-to-canvas.md`](010-seam-suggestion-to-canvas.md)의 변환 결과예요.
- 출력은 [`011-seam-workflow-to-deployment.md`](011-seam-workflow-to-deployment.md)의 `Workflow`예요.
- `OperationSpec`은 선언적이어야 해요. 코드 문자열과 임의 표현식을 담지 않아요.

### 캔버스 레이아웃

`Workflow` 중 캔버스가 소유하는 부분이에요. 배포에 필요한 `outputNodeId`와 `parameters[]`는 [`011-seam-workflow-to-deployment.md`](011-seam-workflow-to-deployment.md)가 정해요.

```ts
type WorkflowNodeKind = "source" | "transform" | "join" | "output";

interface WorkflowNode {
  id: string;
  kind: WorkflowNodeKind;
  title: string;
  subtitle: string | null;
  datasetId: string | null;
  position: { x: number; y: number };
}

interface WorkflowLink {
  id: string;
  source: string;
  target: string;
}

interface Workflow {
  nodes: WorkflowNode[];
  links: WorkflowLink[];
}
```

- `position`은 화면 좌표가 아니라 캔버스 좌표예요. 확대와 이동은 저장하지 않아요.
- `kind`가 `source`인 노드는 GovData Studio 카탈로그의 `datasetId`를 가질 수 있어요. 데이터셋을 아직 고르지 않은 수동 노드는 `null`이고 실행 전에 멈춰요.
- `datasetId`는 제목이나 설명으로 추론하지 않고 원본 카탈로그의 식별자를 그대로 보존해요.
- 없는 노드를 가리키는 링크와 자기 자신으로 가는 링크는 검증에서 막혀요.
- 캔버스 상태는 통째로 덮어써요. 부분 갱신을 하지 않아서 순서 충돌이 생기지 않아요.
- 캔버스는 라이브러리 없이 직접 그려요. 노드 카드, 베지어 링크, 이동과 확대만 필요하고 이 정도는 의존성을 늘릴 만큼 크지 않아요.

### 캔버스 조작

조작 모델은 n8n 에디터를 따라가요. 처음 쓰는 사람이 이미 아는 손버릇을 그대로 쓸 수 있게 하려는 거예요.

| 동작        | 입력                                          | 결과                                                              |
| ----------- | --------------------------------------------- | ----------------------------------------------------------------- |
| 노드 추가   | 사이드 내비게이션의 `노드 추가` 클릭           | 노드 종류를 고르는 모달을 열고, 고르면 파이프 오른쪽 끝에 놓아요  |
| 단일 선택   | 노드 클릭                                     | 그 노드만 선택하고 나머지는 해제해요                              |
| 다중 선택   | `Shift` 또는 `Cmd`/`Ctrl` + 노드 클릭         | 그 노드의 선택 여부만 뒤집어요                                    |
| 범위 선택   | 빈 곳에서 드래그                              | 사각형과 겹치는 노드를 모두 선택해요                              |
| 노드 이동   | 선택된 노드 드래그                            | 선택된 노드가 함께 움직이고 16px 격자에 맞춰요                    |
| 연결        | 사이드 내비게이션의 `연결` 또는 포트 드래그    | 두 노드를 고르는 모달 또는 포트 조작으로 연결해요                |
| 연결 해제   | 링크 클릭 후 `Delete`, 또는 링크 가운데 버튼  | 삭제 확인 모달 뒤 그 링크만 지워요                                |
| 노드 메뉴   | 노드 우클릭                                    | 해당 노드의 `실행`과 `노드 삭제` 메뉴를 열어요                      |
| 삭제        | 선택 상태의 `삭제`, 노드 메뉴의 `노드 삭제`, `Delete` 키 | 삭제 확인 모달 뒤 선택한 노드와 연결을 지워요                  |
| 이동(패닝)  | 휠, 가운데 버튼 드래그, `Space` + 드래그      | 선택을 건드리지 않고 화면만 옮겨요                                |
| 확대 · 축소 | `Cmd`/`Ctrl` + 휠, 툴바 버튼                  | 커서 아래 지점을 고정한 채 40%에서 200% 사이로 바꿔요             |

키보드는 아래만 받아요.

| 키                  | 결과             |
| ------------------- | ---------------- |
| `Delete`/`Backspace` | 삭제 확인 모달을 열어요     |
| `Cmd`/`Ctrl` + `A`  | 노드를 전부 선택해요 |
| `Escape`            | 선택과 연결 드래그를 취소해요 |
| `0`                 | 확대를 100%로 되돌려요 |
| `1`                 | 전체가 보이게 맞춰요 |

연결은 아래를 막아요. 막힌 이유는 드래그 중인 선의 색으로 바로 보여줘요.

- 자기 자신으로 가는 연결
- 이미 있는 같은 방향의 연결
- 순환을 만드는 연결. 파이프는 직렬이라 되돌아오는 흐름을 허용하지 않아요.

## 인수 기준

- [ ] 링크에 자연어를 쓰면 조인 키, 기준 연도, 변환 방식이 명시된 스펙으로 보여요.
- [ ] 사용자가 카드 우클릭의 `실행`이나 상단 `실행`을 선택하기 전에는 실행하지 않아요.
- [ ] 소스 실행은 해당 데이터셋만, 조인·변환·출력 실행은 선행 소스 전체를 REST로 실행해 결과를 보여줘요.
- [ ] 실행 후 모든 노드에서 행 수, 컬럼 수, 결측률, 매칭률을 볼 수 있어요.
- [ ] 조인에서 빠진 행과 빠진 사유를 확인할 수 있어요.
- [ ] 지역명 표기가 다른 두 데이터셋이 시군구 코드로 조인돼요.
- [ ] 정지 조건에 걸리면 그 노드에서 멈추고 이유가 보여요.
- [ ] 노드를 추가하고, 고르고, 옮기고, 연결하고, 지우는 조작이 위 표대로 동작해요.
- [ ] 순환을 만드는 연결과 자기 자신으로 가는 연결은 만들어지지 않아요.

## 실패와 정지 조건

기본은 자동 진행이에요. 아래에 걸리면 그 노드에서 멈춰요.

| 감지                      | 사용자에게 보이는 것        | 진행 여부 |
| ------------------------- | --------------------------- | --------- |
| 조인 결과 0행 / 행 수 급감 | 변화 전후 행 수             | 멈춤      |
| 지역 매칭률 급락          | 매칭률과 빠진 지역          | 멈춤      |
| 타입 불일치, 단위 충돌    | 충돌한 컬럼과 단위          | 멈춤      |
| 결측률 급증               | 컬럼별 결측률               | 멈춤      |

아래는 사용자만 판단할 수 있어요. 막지 않고 보여주기만 해요.

- 이 데이터가 내 질문에 맞나
- 지역 · 기간 범위가 적절한가
- 이 결과가 쓸 만한가
